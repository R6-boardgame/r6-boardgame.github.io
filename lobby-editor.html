發佈設定

發佈會把設定與圖片存進遊戲網站的 GitHub（r6-boardgame/r6-boardgame.github.io），所以需要一把有寫入權限的金鑰。只要設定一次，金鑰只存在這台電腦的瀏覽器裡。

  1. 打開 GitHub 建立金鑰頁（已幫你勾好 public_repo）
  2. Expiration 選 No expiration 或你想要的期限，按最下面 Generate token
  3. 把 ghp_ 開頭的那串貼到下面
